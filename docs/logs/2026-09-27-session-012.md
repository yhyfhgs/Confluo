## 决策/发现

- **视觉**：沿用 [07 §14](../plan/v2/07-frontend-interaction.md) 的"纸与墨"基调（背景 `#f5f4f0`，墨色文字），一级用朱色，二级用青色，标题用宋体。与其余 v2 技术图区分开，定位为对外介绍用图。
- **走向口径**：
  - 线的走向取元数据/最新论文通道中首个列出的连接器族，`v1_bridge(x)` 按 x 计。
  - "经 `x`"且 x 为二级来源时，线穿过该节点。
  - `unpaywall` 只有全文通道，按其自身通道画。
  - 排除、仅外链、仅导入画成空心点；暂无连接器画成浅点，都不画线。盗版影子库合并行不画，在脚注中说明。
- **对账**（脚本重算，与名录一致）：kind 计数与 §4.1 相同；非排除 169；排除类 18（图中画出 17）；暂无连接器 10。
  - 元数据/最新通道用到 `crossref_delegated` 的行数，按本脚本口径为 93，名录 §0 与 §4.1 为 92。差的 1 行是 `medrxiv`：它的 ConnectorFamily 写作"同 `biorxiv`"，名录口径没有展开。图中不标这个数，不受影响。
- **二级分组**：由主 agent 依据 [03](../plan/v2/03-sources-and-corpus-pipeline.md) §2.1 与 §7.7 做单职能归类，多职能来源取主职能（如 DataCite 归权威）。脚注已说明这一点。
- **Work 示意卡**：选 CS/AI 论文路径，即 arXiv v1/v2 → OpenReview 接收 → NeurIPS Proceedings 正式版。字段来源为 Crossref（10.52202）、dblp、OpenAlex、OpenCitations、HF Papers、ORCID，每个来源在名录中都有对应行。标题用骨架条表示，不虚构具体论文。
- **生成器未入库**：生成器是一个 Python 脚本，解析名录 §3 表格、分类后输出 SVG，只放在本 session 的临时目录。名录行变化后，需要重写生成器，或手工调整 SVG。
