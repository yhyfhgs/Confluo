## 决策/发现

- **架构主线**：
  - PostgreSQL 18 单栈；platform 与 personal 两种部署同一代码；v1 维护冻结；
  - "先收割、后联邦"；
  - 合规数据域单向流，派生物继承最严范围；
  - auth-gated 全文在用户侧取回（扩展或本地代理），平台出口不代取；
  - TSRG 统一服务路由、调度、兴趣与反向推送；
  - 推荐 R0 用"共享嵌入 + 每用户 LR"起步，价值模型 Σ V·P̂，北极星为有价值阅读；
  - 双向匹配分三层；
  - 前端为 Deck、瀑布流与详情 Sheet 三件套，3 个一级入口，每日有限批次。
- **调研推翻或修正 v1 的事实**（均需 ADR）：
  - dblp 全站 robots 已禁，改用 DROPS 快照或 SPARQL；
  - SSRN ToU 禁止自动化，降为只取元数据并外链；
  - Crossref 自 2025-12 起按请求类型分池限速；
  - OpenAlex 计量计费，快照改为季度；
  - arXiv OAI 支持类目级 set，v1 的物理 set 推导会失效；
  - PMC 旧数据集下线；
  - bioRxiv 启用新前缀 10.64898。
- **合规自我披露**（调研期间，记录于 [NS §1.4.5](../survey/sources/natural-sciences.md)）：
  - 理科来源调研员对 IOP RSS 与 PubChem PUG-REST 各发出 1 次请求，事后发现两者落在 robots 禁区；未重复，已作为 robots ADR（D-049）的裁决样例；
  - 多 agent 共享出口导致 Crossref 公共池出现 17 次以上 429，改为 6 s 间隔后恢复。
  - 其余调研与 demo 构建的请求均为诚实 UA、低频、遇挑战即停，未使用凭证、未下载全文。
- **编排教训**：Workflow 的缓存按调用顺序前缀命中，失败任务之后的已完成任务会被重跑。续跑时应改用"把已完成结果作为参数传入、显式跳过"的收尾脚本。本次首次续跑发现此问题后立即停止，改用收尾脚本。
