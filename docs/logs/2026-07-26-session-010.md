# 2026-07-26 · session-010 —— D-032：config-home 迁入仓库根（用户架构令：config 归集）

## 背景与决策

- 用户令：把散落 `~/.xxx` 的论文平台 config 归集进项目文件夹统一管理、给 config 专门规范与文件夹。
- 盘点结论：D-025 已把**规范与样例**归集在仓库 `config/`；真实散点仅 3 处——`~/.paper-crawler`
  （真正需人编辑的 config 只有 1KB `config.toml`，其余是 DB/数据/日志）、`~/.kaggle/access_token`
  （外部 kaggle CLI 自有产物）、`~/Library/LaunchAgents/com.papercrawler.openreview-token.plist`
  （launchd 硬约束位置）。
- 用户两轮拍板：① 整个 config-home 迁入项目（否决「仅非敏感层进项目」与「仅登记」）；
  ② 指向机制用 **env**（否决 symlink 过渡——家目录彻底干净）。
- ADR：[D-032](../plan/decision-log.md)；设计随修 [10-config-layout](../design/10-config-layout.md) §3/§6/§8。

## 做了什么

1. **代码对齐**（`c3e8ebc`，分支 `chore/config-home-into-repo`）：新公共 `config.resolve_home()`
   兜底复用点（与 `Config.load` home 链单一同源）；openalex 预算 state 兜底改经之（原
   `Path.home()/".paper-crawler"` 硬编码绕过 env，会静默重建空家目录）；launchd plist 模板
   `ProgramArguments` 显式携 `--home`；护栏指引文案「家目录（仓库外）」→「config-home」。
2. **护栏**（`11f9b39`）：`.gitignore` 锚定 `/.paper-crawler/` 整目录；AC-0.3 守卫测试
   （check-ignore 参数化）+3 条。
3. **迁移执行**：launchctl bootout（发现任务原本就未加载——token 刷新自 07-24 停摆）→ 同卷原子
   `mv ~/.paper-crawler → <repo>/.paper-crawler` → `~/.zshenv` 追加 `export PAPER_CRAWLER_HOME`
   → `--install-launchd` 重装（RunAtLoad 立即真实刷新成功：exit 0、token 写回新路径、0600 保持）。
4. **文档**：D-032 ADR；10-config-layout 修订；config/README 升级**全配置地图**（含 kaggle
   登记不搬、plist 安装产物、env 缺失回落语义）；AGENTS §6.6 **git clean 红线**（禁裸
   `git clean -fdx`，必须 `-e .paper-crawler`）+ 更新日期；elsevier runbook / canary README
   措辞对齐；INDEX 日志范围 001–010。
